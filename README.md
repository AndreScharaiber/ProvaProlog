# Descrição
Este projeto implementa um sistema especialista em Prolog que recomenda trilhas de carreiras na área de Computação com base nas respostas do usuário a um questionário de afinidade 

O sistema pode ser usado:
- **Modo interativo:** responder perguntas diretamente pelo terminal
- **Modo de teste automatizado:** carregar perfis predefinidos para simular respostas de diferentes alunos

---

# Como executar

1. Abra o SWI-Prolog.
2. Carregue o código: swish.pl
3. Use o comando: ?-iniciar
4. Responda o formulário e receba sua resposta
